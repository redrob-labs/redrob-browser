      Models

      Which model answers your tasks. The built-in engine needs no setup. Your own provider needs a key, which is stored through this machine's keystore and is never shown again — not to this page, and not to any page.

        Connect a provider

        Must be an https endpoint that speaks the OpenAI chat-completions shape. Tasks you run against your own provider send that provider the pages they read.

        Passwords

        Logged-in sites are where the agent is most useful, so how passwords are handled matters here. The credentials themselves live in this browser's own password manager — this page decides whether it offers to save them.

        Command line, MCP and scripts

        Two ways to drive this browser from outside it. One needs no setup; the other is a local socket, and it is off until you turn it on.

        From a terminal, with no setup

        redrob --redrob-task="summarise the page I have open"

        Starts the task in the browser you already have running and opens its tab. Nothing is printed back: the channel that carries a command line to a running browser answers with an acknowledgement and no payload, so there is no output and no exit code to read. That is the channel's shape, not a missing feature — use the endpoint below when the answer has to come back to the terminal.

        Local endpoint

        Listening on nothing

        Serves three things: a CLI that can stream a task's answer back, an MCP server at POST /mcp so another agent can call this browser as a tool, and the same verbs one at a time for scripts. Loopback only, on a port the system picks, and every request needs a token generated fresh each launch — programs read the address and the token from redrob-cli.json in this profile's folder.

        Off by default on purpose. Any program on this machine that can read that file can then do anything you can do in this browser, including on sites you are signed in to. Turn it on when you have a reason to, and turn it off after.
