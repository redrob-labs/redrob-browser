# Brand files

`symbol-white-192.png` is the Redrob design system's white symbol (`Favicons/`), copied byte for byte from
redrob-launcher's `assets/brand/`, where `SHA256SUMS` pins it. Never redrawn, recolored or resized here; the
setup draws it on its Redrob Blue panel.
